# 두레 전교 시보 · 전자시계 HUD

교실과 방송실에서 함께 쓰는 **전자시계 웹앱(PWA)** 입니다.
설치하면 바탕화면 아이콘으로 실행되고, **인터넷이 끊겨도 그대로 동작**합니다.

## 주요 기능

| 구분 | 내용 |
| --- | --- |
| 시정표 시계 | 현재 교시·과목·남은 시간을 큰 글씨로 표시, 이동 수업 표시 |
| **주간 시간표 한눈에 보기** | 월~금 교시 시간·과목을 한 표로 비교, 과목명은 표에서 바로 입력 |
| **요일별 시정표** | 월~금 요일마다 교시 시간을 다르게 (수요일 단축 수업 등). 요일별 복사·되돌리기 지원 |
| **주간 템플릿 6칸** | 한 주의 요일별 설정을 통째로 저장하고 버튼 한 번으로 전환 |
| **종소리 아카이브** | 종소리를 원하는 만큼 저장해 두고 **칸마다 골라서** 지정 (교시·점심·저녁·방과후 각각) |
| **한눈에 보기** | 올린 종소리를 격자로 펼쳐 **어디에 쓰이는지·안 쓰이는지** 한 번에 확인 |
| **기상 시간·기상송 (기숙사)** | 일~토 요일마다 기상 시각을 따로, 기상송도 여러 개 순서대로 |
| 전교 시보 | 지정한 시각에 음원을 **순서대로** 재생 (기상송 → 녹음 방송) |
| **요일별 아침방송** | 시보마다 월·화·수·목·금 각각 다른 방송 파일 재생 |
| **예비종 · 시작종 · 끝종** | 칸마다 셋을 **따로** 지정 — 예비종은 "몇 분 전"까지 칸별로 |
| **기본 종소리 자동 지정** | 파일 이름만 보고 올리는 순간 예비·시작·끝·기상 자리에 알아서 배치 |
| **소리 잠김 경고** | 브라우저가 소리를 막고 있으면 화면에 크게 알림 — 첫 종을 놓치지 않게 |
| 타이머 · 스톱워치 | 활동 시간 관리, 종료 시 알람음·음성 안내 |
| 배경 · 색상 | 투명 / 크로마키 그린·블루 지원 → OBS 합성, PPT 위에 띄우기 |
| **자유 시간 칸** | 칸 이름을 자유롭게 — 1교시·조회·점심시간·저녁시간·방과후 무엇이든 |
| 시간표 자동 배치 | 수업·쉬는시간 길이와 **점심·저녁 시각**을 넣으면 교시를 알아서 배치 |
| 템플릿 | 학년·학기별 설정을 저장해 두고 골라 쓰기 |
| **오프라인** | 서비스 워커로 앱 전체를 저장 — 인터넷 없이 실행 |
| **앱 설치** | 바탕화면·작업표시줄 아이콘, 주소창 없는 전체 화면 |
| **화면 꺼짐 방지** | 수업 중 절전 모드로 화면이 꺼지지 않게 유지 |
| **전체 백업 · 복원** | 설정 + **음원 파일까지** 한 파일로 저장해 다른 PC로 이동 |

## 주간 시간표 한눈에 보기

설정을 열면 `시정표 · 시간표` 위에 **월~금 전체가 한 표**로 나옵니다.

| 읽는 법 | 내용 |
| --- | --- |
| 행 | 1교시 → 마지막 교시, 중간에 **점심·저녁·방과후** 줄, 맨 아래 **마침**(하교) 시각 |
| 열 | 월 · 화 · 수 · 목 · 금. 요일 이름 아래에 `전용 / 공통`(요일별 모드) 또는 `7교시` 표시 |
| 칸 | 위 = **시작~끝 시각**(눌러서 바로 수정), 아래 = **과목명 입력칸** |
| 오늘 | 오늘 요일 열이 시안색으로 강조됩니다 |
| `↔` | 이동 수업 표시. 누르면 켜지고 보라색이 됩니다 |
| 점선 빈칸 | 그 요일에는 없는 교시 (예: 수요일 단축 수업) |

- **시각을 누르면 그 자리에서 고칩니다.** 시작·끝 시각과 칸 이름(1교시 / 조회 / 점심시간 …)을 함께 바꾸고 [확인]을 누르면 끝입니다.
- **과목명은 표의 아래 칸에 바로** 칩니다.
- **요일 이름을 누르면** 그 요일의 시정표 편집으로 바로 넘어갑니다.

### 설정창 넓게 보기

설정 패널 오른쪽 위 **`⇔` 버튼**을 누르면 창이 넓어져 표가 시원하게 보입니다.
다시 누르면 원래 폭으로 돌아가고, 선택한 폭은 다음에 열 때도 그대로 유지됩니다.
(기본 660px · 넓게 1180px · 화면이 좁으면 화면 폭에 맞춰 자동으로 줄어듭니다.)

## 요일별 시정표 쓰기

`설정 → 시정표 · 시간표 → 요일별로 다른 시정표`를 켜면 월~금 탭이 살아납니다.

- 켜는 순간 **지금 시정표를 다섯 요일에 복사**할지 물어봅니다. 대부분 여기서 [확인]을 누르고 다른 요일만 고치면 됩니다.
- 탭 아래 작은 글씨가 그 요일의 상태입니다. `7칸`은 전용 시정표, `공통`은 공통 시정표를 쓰는 요일입니다.
- 특정 요일만 다르게 하려면 그 요일 탭에서 **[이 요일 따로 만들기]** → 교시 시간을 고칩니다.
- **[이 요일을 월~금 전체에 복사]**, **[다른 요일에서 복사…]**, **[공통 시정표로 되돌리기]** 로 요일 사이를 옮길 수 있습니다.
- 자동 배치는 `자동 배치 (수)` 처럼 **선택한 요일에만** 적용되고, `[월~금 전체]` 버튼으로 다섯 요일을 한 번에 만들 수도 있습니다.
- **칸별 종소리도 요일을 따라갑니다.** 수요일 시정표를 편집 중이면 아래 시간 설정의 종소리도 수요일 것입니다.

끄면 다시 모든 요일이 공통 시정표를 씁니다. 요일별로 만들어 둔 내용은 지워지지 않고 그대로 남습니다.

## 요일별 아침방송

`설정 → 전교 시보 · 방송 스케줄`에서 시보를 하나 만들고 **[요일별 다른 음원]** 을 켜세요.

- 선택한 요일마다 블록이 하나씩 생기고, 각 요일에 **다른 파일을 순서대로** 넣을 수 있습니다.
- 예) 월요일 = 주간 조회 음악 → 교장선생님 말씀, 화~금 = 기상송 → 아침 방송
- 요일 블록마다 **[▶ 미리듣기]** 로 그 요일 것만 확인하고, **[전체 요일에 복사]** 로 나머지 요일에 같은 구성을 뿌릴 수 있습니다.
- 켤 때 기존 음원 구성이 선택된 요일들에 자동으로 복사되므로, 다시 처음부터 넣을 필요가 없습니다.

## 주간 템플릿 (6칸)

설정 패널 맨 위에 6개의 버튼이 있습니다. 기본 이름은 `정상 주간 / 시험 주간 / 단축 수업 / 행사 주간 / 체험학습 / 방학·특별` 이고, **[편집]** 에서 원하는 이름으로 바꿀 수 있습니다.

- **비어 있는 칸을 누르면** 지금 설정을 그 칸에 저장합니다.
- **저장된 칸을 누르면** 그 주간 설정이 요일별로 한 번에 적용됩니다.
- 담기는 내용: 요일별 시정표 · 공통 시정표 · 요일별 과목 · 전교 시보(요일별 음원 포함) · **기상 시각·기상송** · 칸별 종소리 · 예비종 · 자동 배치 설정
- 담기지 **않는** 내용: 종소리 아카이브의 파일, 색상·배경 → 주간을 바꿔도 그대로 유지됩니다.
- **[편집]** 모드에서 각 칸마다 `이름` / `저장·덮어쓰기` / `비우기` 를 할 수 있습니다.
- 적용한 뒤 시정표를 손으로 고쳤다면 `[편집] → [덮어쓰기]` 로 다시 저장하세요.

> 음원은 ID로만 참조하므로 주간 템플릿을 바꿔도 음원 파일을 다시 올릴 필요가 없습니다.

## 시간 설정 — 칸 이름을 자유롭게

`설정 → 시정표 · 시간표 → 시간 설정`에는 칸이 하나씩 카드로 놓입니다.

```
[ 조회      ] 08:50 ~ 09:35  [수업 ▾] ✕
  예비종 [ 5 ]분 전 [예비 차임 ▾] ▶   시작종 [댕댕 시작종 ▾] ▶   끝종 [차임 끝종 ▾] ▶
```

- **이름은 완전히 자유입니다.** `1교시` `조회` `점심시간` `저녁시간` `방과후` `동아리` 무엇이든 적으세요.
  비워 두면 구분에 맞는 기본 이름(1교시 · 쉬는 시간 · 점심시간 …)이 자동으로 보입니다.
- **구분**은 색과 판정에만 쓰입니다 — 수업 / 쉬는시간 / 점심 / 저녁 / 방과후 / 기타.
- 칸마다 **예비종 · 시작종 · 끝종을 각각 따로** 고릅니다. `▶` 로 바로 들어 볼 수 있어요.
- `[+ 칸 추가]` 는 마지막 칸이 끝나는 시각부터 이어서 새 칸을 만듭니다.

## 종소리 아카이브 · 한눈에 보기

`설정 → 🔔 종소리 · 음원 아카이브` 에 종소리를 원하는 만큼 넣어 둡니다.

- `[+ 음원 파일 추가]` — 한 번에 **여러 파일**을 선택할 수 있습니다.
- **올리는 순간 자동으로 자리를 잡습니다.** 파일 이름에 아래 낱말이 들어 있으면 기본 종소리로 바로 지정됩니다.

  | 이름에 들어 있으면 | 들어가는 자리 |
  | --- | --- |
  | 예비 · 준비 · pre · prep | 기본 예비종 |
  | 시작 · 시업 · 입실 · start · begin | 기본 시작종 |
  | 끝 · 종료 · 마침 · 하교 · end · finish | 기본 끝종 |
  | 기상 · 아침 · 모닝 · wake · morning | 비어 있는 요일의 기상송 |
  | 타이머 · 알람 · timer · alarm | 타이머 종료음 |

  이미 사람이 직접 골라 둔 자리는 건드리지 않습니다. 이름이 애매하면 **[🔔 기본 종소리 자동 지정]** 버튼을 눌러 올린 순서대로 채울 수 있습니다.
- 아카이브 위쪽 알약 표시로 **지금 기본 종소리가 어떤 파일인지** 한눈에 확인합니다.
- 목록의 **이름을 눌러 바로 바꿉니다** (예: `bell_03.mp3` → `1교시 시작종`).
- 여기 넣은 음원은 **시간 설정의 모든 칸**, **전교 시보**, **타이머 종료음**에서 골라 쓸 수 있습니다.
- 칸의 종소리를 `기본 종소리`로 두면 아카이브 위쪽의 **기본 시작종/끝종**을 따릅니다. `없음`으로 두면 그 칸은 울리지 않습니다.
- 점심·저녁·방과후 칸은 **직접 지정했을 때만** 울립니다 (수업 칸은 지정하지 않으면 기본 종을 씁니다).

## 예비종 · 시작종 · 끝종 따로 설정하기

칸 하나에 **세 가지 종**을 각각 다르게 넣을 수 있습니다.

| 종류 | 언제 울리나 | 켜고 끄는 법 |
| --- | --- | --- |
| **예비종** | 그 칸이 시작하기 **N분 전** | `예비 시간(분)`을 **1 이상**으로 두면 켜집니다. **0이면 사용 안 함** |
| **시작종** | 칸이 시작하는 시각 | 음원을 고르면 그 소리로, `없음`이면 안 울림 |
| **끝종** | 칸이 끝나는 시각 | 음원을 고르면 그 소리로, `없음`이면 안 울림 |

- 아카이브의 **기본 예비종 / 기본 시작종 / 기본 끝종** 세 가지를 먼저 정해 두면, 칸에서 `기본 종소리`로 둔 곳은 그 소리를 씁니다.
  칸의 선택 상자에 `기본 종소리 · bell_start` 처럼 **실제 파일 이름이 같이 표시**되어 무엇이 울릴지 바로 보입니다.
- **쉬는 시간 칸에는 종소리 설정이 아예 없습니다.** 앞 칸의 끝종과 다음 칸의 시작종이 대신 울립니다.
- 예비종은 **모든 종류의 칸**에 붙일 수 있습니다 — 1교시 5분 전 예비종, **점심 10분 전 예비종**, 저녁 5분 전 예비종, 방과후 예비종 모두 가능합니다.
- 주간 시간표에서 예비종이 켜진 칸은 **`⏰5` 같은 배지**로 표시되어 어느 칸에 예비종이 걸려 있는지 한눈에 보입니다.
- 한꺼번에 걸려면 `종소리 동작 → 일괄 적용`에서 분을 정하고 **[예비종 켜기]** — 지금 편집 중인 요일의 수업 칸 전체에 적용됩니다. **[예비종 끄기]** 로 한 번에 해제합니다.

> 이전 버전의 `점심 예비종`·`저녁 예비종` 설정은 업데이트할 때 자동으로 옮겨집니다.
> 점심 예비종은 **점심 칸의 예비종**으로, 저녁 예비종은 **전교 시보 "저녁 예비종"** 한 건으로 바뀝니다.

### 여러 개를 한눈에

음원이 많아지면 이름만으로는 헷갈립니다. 오른쪽 위 **[한눈에]** 를 누르면 격자로 펼쳐집니다.

- 카드마다 **이름 · 용량 · 재생 길이**와 함께 **어디에 쓰이는지 배지**가 붙습니다.
  `1교시 시작` `기본 끝종` (시안) / `기상 월·화` (노랑) / `아침 기상방송` (보라)
- 아무 데도 안 쓰는 음원은 **점선 테두리 + `미사용`** 으로 표시되어 정리하기 쉽습니다. 위쪽 개수 옆에도 `미사용 2` 처럼 나옵니다.
- 음원이 6개를 넘으면 **검색창**이 나타납니다.
- **[▶ 모두 미리듣기]** 로 올린 순서대로 전부 이어 들어 볼 수 있습니다 — 어떤 파일이 어떤 소리인지 확인할 때 편합니다.
- **[목록]** 보기로 돌아가면 한 줄에 이름·쓰임새·용량이 압축되어 보입니다. 고른 보기는 다음에도 유지됩니다.

## 기상 시간 · 기상송 (기숙사)

`설정 → 🌅 기상 시간 · 기상송` 에서 **요일마다 다른 기상 시각과 기상송**을 정합니다.

- **[기상 방송 사용]** 을 켜야 동작합니다. 끄면 아래 요일 설정과 상관없이 울리지 않습니다.
- 월 → 금 → 토 → 일 순으로 일곱 줄이 놓입니다. **주말(토·일)은 붉은 띠**로 구분됩니다.
- 줄마다 **스위치 · 기상 시각 · 기상송 목록**이 있습니다. 스위치를 끄면 그 요일은 깨우지 않습니다(시험 다음 날, 휴일 등).
- **[+ 기상송]** 으로 그 요일에 틀 곡을 **여러 개 순서대로** 넣습니다.
  예) 월요일 = 잔잔한 기상송 → 주간 안내 방송, 화~금 = 기상송만, 토 = 08:00 늦은 기상송
- **[▶]** 로 그 요일 기상송만 미리 들어 봅니다. 기상송을 하나도 넣지 않으면 기본 벨이 울립니다.
- 아래 도우미 버튼: `월요일을 화~금에 복사` · `월요일을 주말에도 복사` · `주말 기상 끄기`
- 기상 방송은 다른 시보보다 **먼저** 울립니다.

## 자동 배치 — 점심·저녁 시각 지정

수업·쉬는시간 길이와 교시 수를 넣고, **점심·저녁·방과후는 시각으로** 지정합니다.

- 점심을 `12:00 ~ 13:00` 으로 두면 **다음 교시는 정확히 13:00에 시작**합니다.
  (이전 버전에서 점심 뒤에 쉬는시간이 한 번 더 붙어 13:10이 되던 문제를 고쳤습니다.)
- 고정 구간 앞에 교시가 못 들어가면, 그 시각까지가 **쉬는시간으로 채워져** 빈 구멍이 생기지 않습니다.
- 각 고정 구간은 스위치로 켜고 끄며, **이름도 바꿀 수 있습니다**(점심시간 / 중식 / 저녁시간 …).

## 소리가 안 날 때

브라우저는 **사람이 한 번 누르기 전까지 소리를 막습니다**. 방송용 PC에서 아침에 켜 두면 첫 종을 놓치는 원인이 바로 이것입니다.

이 앱은 그 상황을 스스로 알아차립니다.

- 울릴 것이 예약되어 있는데 소리가 잠겨 있으면 **"소리가 잠겨 있어요"** 안내가 화면에 뜹니다. **[소리 켜기]** 를 누르면 그 자리에서 풀리고 확인음이 납니다.
- `설정 → 앱 · 오프라인` 의 상태 칩에 **`소리 준비됨` / `소리 잠김 — 화면 클릭`** 이 항상 표시됩니다.
- 같은 화면의 **[🔊 소리 켜고 테스트]** 로 지금 실제로 소리가 나가는지 확인하세요. **아침에 이 버튼 한 번**이 가장 확실합니다.
- 화면 아무 데나 클릭하거나 키를 눌러도 잠금은 풀립니다.

### 그 밖의 재생 문제

- 파일을 못 찾거나 형식이 맞지 않으면 **조용히 넘어가지 않고** 화면에 파일 이름과 함께 알려 줍니다.
- 음원이 메모리에 없으면 저장소에서 **자동으로 다시 꺼내** 재생합니다.
- 재생은 오디오 요소 **하나를 계속 재사용**합니다 — 브라우저 자동재생 제한을 덜 타고, 여러 곡을 이어 틀 때도 끊기지 않습니다.
- 소리가 작으면 아카이브의 **전체 볼륨**을 확인하세요. PC 자체 볼륨·출력 장치(스피커 선택)도 함께 점검하면 좋습니다.

## GitHub Pages로 배포하기

### 1. 저장소 만들기

GitHub에서 새 저장소를 만듭니다. 예: `dure-hud`

### 2. 파일 올리기

이 폴더의 내용을 저장소 **최상위**에 그대로 올립니다.
(웹 화면에서 올릴 경우 `Add file → Upload files`에 폴더째 끌어다 놓으면 됩니다.)

터미널을 쓴다면:

```bash
cd dure-hud
git init
git add .
git commit -m "두레 전교 시보 HUD 웹앱"
git branch -M main
git remote add origin https://github.com/사용자이름/dure-hud.git
git push -u origin main
```

### 3. Pages 켜기

저장소 → **Settings → Pages** →
**Source** 를 `GitHub Actions` 로 선택하면 끝입니다.
(포함된 `.github/workflows/deploy.yml` 이 자동으로 배포합니다.)

`Source` 를 `Deploy from a branch` 로 두고 `main / (root)` 를 골라도 동작합니다.

### 4. 접속

```
https://사용자이름.github.io/dure-hud/
```

> 모든 경로가 **상대 경로**로 되어 있어 저장소 이름이 무엇이든 그대로 동작합니다.
> `.nojekyll` 파일이 포함되어 있어 Jekyll 처리 없이 정적 파일이 그대로 서빙됩니다.

## 오프라인은 어떻게 동작하나요?

- `sw.js` (서비스 워커)가 첫 방문 때 **HTML · 글꼴 · 아이콘**을 브라우저에 저장합니다.
- 두 번째 방문부터는 저장된 파일로 먼저 열리므로 **네트워크가 없어도 즉시 실행**됩니다.
- Pretendard 글꼴을 CDN이 아닌 `assets/fonts/` 에 **직접 포함**했기 때문에, 인터넷이 없어도 글자 모양이 그대로 유지됩니다.
- 업로드한 **음원 파일은 IndexedDB**에, **설정은 localStorage**에 저장됩니다. 이 둘은 서비스 워커와 무관하게 항상 오프라인에서 동작합니다.

### 업데이트

`sw.js` 맨 위의 `VERSION` 값을 올리고 다시 배포하면,
접속한 기기에 **"새 버전이 준비됐어요"** 배너가 떠서 한 번 누르면 갱신됩니다.
설정과 음원은 그대로 유지됩니다.

## 방송실에서 쓰는 팁

1. 방송용 PC에서 앱을 **설치**하고 시작 프로그램에 등록해 두세요.
2. 브라우저 소리 정책 때문에 **화면을 한 번 클릭**해야 자동 재생이 시작됩니다. 아침 부팅 후 `설정 → 앱 · 오프라인 → [🔊 소리 켜고 테스트]` 를 한 번 눌러 두세요. 잠겨 있으면 앱이 먼저 알려 줍니다.
3. `설정 → 앱 · 오프라인 → 화면 꺼짐 방지`를 켜 두면 절전 모드로 화면이 꺼지지 않습니다.
4. 교실 PC로 설정을 옮길 때는 `설정 → 전체 백업 · 복원 → 내보내기`로 만든 `.dhudbak` 파일을 옮겨 `불러오기` 하세요. **음원·요일별 시정표·주간 템플릿까지 함께** 복사됩니다.
5. 시험 주간처럼 시정표가 통째로 바뀌는 주는, 미리 주간 템플릿에 저장해 두었다가 그 주 월요일 아침에 버튼 하나만 누르세요.
6. 기숙사 기상 방송은 `설정 → 🌅 기상 시간 · 기상송`에서 요일마다 시각과 곡을 정해 두면 매일 자동으로 나갑니다.
7. OBS 합성이 필요하면 배경을 `크로마키 그린`으로 두고 브라우저 소스로 캡처하세요.

## 폴더 구조

```
.
├── index.html                  앱 본체 (단일 파일)

│   ├── fonts/                  Pretendard 서브셋 (오프라인용)

├── tools/
│   └── make_icons.py           아이콘 재생성 스크립트
└── .github/workflows/deploy.yml  Pages 자동 배포
```
